FacetUI is a UI library for Roblox scripts. It is similar to Wind UI but
with a darker glass look and a few extra features. The main one is the
mini player mode, where you can double click the title bar to shrink the
window into a small floating pill you can drag around.

It has all the normal components like toggles, sliders, dropdowns, multi
dropdowns, keybinds, colorpickers, textboxes, and notifications. Configs
save automatically per game, and you can have multiple named profiles.
There is also a built in keysystem if you want to gate the script.
